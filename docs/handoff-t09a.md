## 实际修复

1. **契约局结算读档后无法再次保存。** JSON 将数字读成浮点数，RunModel 与排行榜会标准化契约快照，但 `last_run_summary.challenge` 仍保留原始类型。保存校验比较两个嵌套字典时不相等，导致刚加载的结算档案、随后学习天赋或解锁技能的保存被拒绝。GameSession 现在对合法结算契约采用同一 v1 标准化方式；不放宽校验，不改变版本号，不清档。零契约也属于现代契约，因此同样受影响。
2. **旧保存失败提示残留。** 成功保存后恢复为迁移提示或空提示；旧错误不再一直留在后续刷新中。
3. **教程升级页遮挡。** V06 技能卡增高后，返回靶场按钮底部与教程说明条相交。本次调整教程内的面板高度、位置和间距，保留六张完整卡片与返回按钮；正式技能页不变。960×540 与 1280×720 截图和点击通过。
