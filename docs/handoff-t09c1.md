# T09-C1 — 本机持续运行与 Windows 独立试玩包

2026-10-20。本包完成 T09-C 的本机首轮检查与导出。**下一包 T09-C2：高密度齐射性能优化**；低配、跨屏 DPI、长时间听感与一小时以上持续运行仍未验收。

## 交付

- `builds/RainyArrow-windows-x64.zip`：Windows x64 独立试玩包，约 41.6 MiB。解压后运行 `RainyArrow.exe`，同目录保留 `RainyArrow.pck`；无需安装 Godot。此包未签名、未发布到 GitHub。
- 压缩包使用六文件白名单：程序、PCK、引擎／第三方许可、GeneralUser GS 许可、中文说明、SHA256 清单。不含引擎编辑器、参考曲、工具、测试或玩家存档。
- `export_presets.cfg` 与 `tools/export-windows.ps1` 提供可复现导出；`tools/setup-windows-templates.py` 从 Godot 官方模板 ZIP 按字节范围获取 Windows x64 模板，校验 ZIP CRC。完整模板包约 1.28 GB，本机只提取 Windows debug/release 与版本文件，放在忽略的 `.tools` 内。
- 首次仅按主场景导出遗漏了通过全局类引用的脚本，独立启动出现类缺失。已改为导出运行资源并显式排除开发目录、候选音乐，重新打包及验证成功。未改动战斗数值、玩家存档结构或游戏规则。

## 实时压力测量

本机 i9-13900HX、RTX 4060 Laptop GPU、Godot 4.7.2、Compatibility/OpenGL，1280×720，60 帧上限、120 Hz 物理，Dummy 音频；两场景单独运行，期间没有并行导出或其他游戏测试。未锁定功耗和系统后台负载。

人工耐久场景每秒发射 32 支母箭，开穿透、分裂、弹射、回声与靶心回响。普通场景九面高血量靶，第一面扩大以保证真实穿出分裂；Boss 为高血量二阶段。弹药及生命人为增加，仅用于稳定施压，**不作为自然构筑、胜率或平衡证据**。

| 场景 | 拉弓 | 峰值箭 | 峰值浮字／特效 | 每次拉弓子箭上限 | 帧间隔均值／P95／P99／最大值 |
| --- | ---: | ---: | --- | ---: | --- |
| 普通靶 | 119 | 389 | 24／64 | 64 | 32.74／46／56／178 ms |
| Boss | 120 | 364 | 24／64 | 64 | 16.67／18／20／37 ms |

帧间隔由真实 `process_frame` 墙钟时间计算，剔除前 15 秒；包含脚本、绘制和调度，不是 V07 的固定步长重放。普通靶极端齐射平均约 30.5 帧，**未达到稳定 60 帧**。这是下一包需要定位的明确问题。伤害标签虽有数量上限，极端拥挤的信息可读性仍需继续改善。

从约第 20 秒至最后一次采样，Godot 跟踪的静态内存变化：普通靶 +1,288,544 字节，Boss −687,090 字节；没有超过本轮 32 MiB 的增长报警线。此指标不是进程全部内存，也不证明没有长周期泄漏。停止发射并等待寿命结束后，两场景箭矢、结算队列、子箭账本、浮字与特效清空，Boss 韧甲账本也清空；回收后场景节点分别为 85／69。

## 本地复现

```powershell
./tools/validate-desktop.ps1 -Mode Window
./tools/validate-desktop.ps1 -Mode Window -AudioDriver WASAPI
./tools/validate-desktop.ps1 -Mode Soak -Seconds 120
python ./tools/setup-windows-templates.py
./tools/export-windows.ps1
./tools/validate-export.ps1
./tools/validate-boss-pacing.ps1 -Mode Tests
```

Soak 的 `Seconds` 是每个场景的时长，上限 1800；默认 120 秒。先安装 `tools/setup.ps1` 所需引擎，并执行一次 Test 以完成项目资源导入。导出后的运行、日志与截图放在独立测试目录；`builds`、`artifacts`、`.tools` 均被 Git 忽略。

发行程序默认存档在 `%APPDATA%\AzVGames\ArrowsLikeRain\save.json`。开发入口 `Play.cmd` 使用 `.tools/profile` 中的独立存档，导出不自动复制或合并玩家进度。

证据：`artifacts/t09c-soak.json`、`t09c-desktop.json`（首次 Dummy）、`t09c-desktop-WASAPI.json`、`t09c-export.json`、`t09c-release-save-roundtrip.json`、`t09c-release-*.png`。原始压力日志 `.tools/t09c-soak_desktop.log`；后续脚本日志带音频后端后缀。系统证书库读取警告仍存在；最终测试没有脚本错误。
