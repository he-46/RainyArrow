计划日期：2026-10-17；更新：2026-10-20。状态：V01–V07、T09-A、T09-B1/B2/B3 与 T09-C1 已完成；下一包 T09-C2。结果与实机截图见 [V01 交接](handoff-v01.md)、[V02 交接](handoff-v02.md)、[V03 交接](handoff-v03.md)、[V04 交接](handoff-v04.md)、[V05 交接](handoff-v05.md)、[V06 交接](handoff-v06.md)、[V07 交接](handoff-v07.md)、[T09-A 交接](handoff-t09a.md)、[T09-B1 交接](handoff-t09b1.md)、[T09-B2 交接](handoff-t09b2.md)、[T09-B3 交接](handoff-t09b3.md)、[T09-C1 交接](handoff-t09c1.md)。本机短时持续运行及导出已检查；极端齐射性能、低配和跨 DPI 仍待验收。

## 目标与现状

目标画面：月夜林地中，一名轻装游侠正在与机关靶和巨型装甲靶交战。森林有纵深，营地有暖意，拉弓与命中有力度，玩家能清楚分辨目标、箭矢、技能状态和下一步操作。与《月下弓弦》《营火来信》《林间交锋》的场景分工一致。

依据当前工程与截图：

- `CosmeticDrawing` 用矩形、线条绘制人物与装备，人物缺少可读的轮廓和动作。
- `ArcheryWorld`、`MenuBackdrop` 以重复树形构成森林，前后景层次、地表细节与场景身份较弱。
- 普通靶的表面与受损状态简单；Boss 需要在体量之外，让核心、护板、材质和阶段变化更清楚。
- HUD 主要靠文字解释，属性占据常驻底栏；主动技能缺少图形识别，能量就绪的视觉信号较弱。
- 神器、天赋与技能页以文字卡片为主，浏览不同构筑时缺乏图标记忆点。
- 现有射箭输入、碰撞、存档和装扮均已工作，画面升级须逐项接入现有事件和外观接口。

当前基线：主动技能首版、三首 BGM 已接入，最近记录为 3053 项自动检查、13 项主动技能窗口检查通过。这是升级前基线，不是本计划的验收结果。

## 视觉规范

### 风格

- 采用轮廓清晰的像素绘制：青灰森林、暖色皮革与木材、局部金色月光。
- 游侠的识别点是兜帽、短披风、护臂、箭袋、弓；动作表现敏捷、专注。
- 场景保持夜林气氛，交战区提高目标与箭头对比度；近处枝叶只在边缘出现。
- 基础材质采用少量色阶与明确像素块；界面正文用清晰中文字体。标题可装饰，数字与长说明优先可读。
- 控制环境动画幅度：树梢轻动、营火跳动、少量飘叶；不使用持续横向移动的背景制造追逐假象。

### 像素与资源约定

- 沿用世界 640×360 坐标、默认 2 倍显示与 1280×720 界面基准，不在第一包重做坐标体系。
- 世界资源使用最近邻采样；场景贴图按层交付，不能用一张大背景遮住可交互物体。
- 图标源尺寸优先 24×24 或 32×32；同一套保持统一尺寸、描边和光源方向。
- 游侠初步使用 64×80 透明画布，包含披风活动余量；脚点、握弓点和箭头发射点必须对齐现有锚点。实际有效轮廓在 V02 检查后确定。
- 独立的装扮换色与装备层继续可用，不能把整个人物和弓合并为不可换装的一张图。
- 中文与可变数值由界面绘制，不烘焙进图片。外来素材记录来源和许可；生成素材也需切图、去边、统一像素尺度与实机检查。
- 资源按用途放入 `assets/art/environment/`、`characters/`、`targets/`、`ui/`、`vfx/`；尺寸、锚点与动画名记录在素材清单中。以上目录在对应实施包中建立。

### V01：先交付一张真正升级后的战斗画面

已完成：分层夜林、苔石射箭台、底部主动技能图标与能量刻线、R 属性面板、F1 操作说明、首次射箭后弱化提示。3069 项自动检查、26 项 V01 窗口检查通过，1280×720 与 960×540 截图已核对。环境使用代码绘制，无外部贴图依赖。

工作范围：`ArcheryWorld` 的环境表现、`GameHUD`、必要的主题与场景资源。

1. 制作夜空／远林、主林地、地面与边缘前景三组视觉层；加入树干、草地和射箭台材质。
2. 调整明暗分布：弓手与靶区轮廓清晰，箭矢路径内背景保持低对比。前景不遮住边界或弹射位置。
3. HUD 顶部保留金币、剩余拉弓、等级经验等主要资源；Boss 血条按战斗状态出现。
4. 主动技能区使用独立图标、能量刻度、消耗标记和剩余次数。常驻短说明，详细规则放悬停提示。
5. 把底部长串属性转为可展开的属性面板，并在局内升级页保留完整比较；确保现有数值调试信息仍可访问。
6. 初始操作提示在完成实际射箭后弱化；玩家仍可从教程或帮助找到操作说明。

验收：同一靶场截图能明显看出景深与主次；960×540 和 1280×720 不溢出；不会遮挡弓的点击与拖拽区域；展开面板能正确拦截输入；背景动画不消费战斗随机数。保留角色与目标旧图作为此阶段的可用资源，不为赶首屏同时重画所有对象。

### V02：游侠动作与装备

已完成：兜帽／短披风／箭袋／护臂／靴子分层绘制，待机、拉弓、蓄满、松弦、装填、施放六种姿态，弓臂形变和弦锚点统一，箭头箭羽重绘；三套装扮与现有预览沿用同一绘制接口。3100 项自动检查、56 项窗口检查通过。采用代码绘制，无需新增位图动画资源。

- 游侠：待机呼吸、拉弓姿态、蓄满保持、松弦、装填、施放动作。优先少帧、清晰姿势，再补过渡。
- 拉弓姿势由实际拉力驱动，装填动作由真实剩余装填时间驱动；动画不能延迟输入响应。
- 弓的弯曲、手臂、弦与箭头保持对齐；释放有短促回弹与披风跟随动作。
- 归一大箭、多箭、装扮换色和不同弓外观继续适配。

验收：取消拉弓、快速连射、疾风零装填、暂停与继续时动作状态正确；人物动起来但命中判定、发射位置和伤害不变。默认外观与已解锁装扮均能预览和装备。

### V03：普通靶与 Boss

已完成：三类靶材质、真实靶心色带、低血量裂纹、机关 Boss 装甲／核心／移动护板、阶段二暖色机械细节，以及无碰撞的短暂碎裂。3153 项自动检查、52 项窗口检查通过；两种窗口尺寸、真实护板接触、重生与读档均已验证。

- 普通靶补齐木纹、包边、支架或悬挂关系；靶心、实际受击宽度保持一致。
- 用材质区分基础木靶和装甲靶；低血量增加裂纹，击倒时表面破碎后消失。
- Boss 强化“巨型机关装甲靶”的结构：底座、外甲、核心、前置护板分别处理。
- 第二阶段通过核心和护板动作清楚提示；伤害提示、血条和弱点不能互相盖住。

验收：外观不暗示不存在的可命中区域；护板宽度、核心区域与实际碰撞匹配。入场清靶的碎裂与玩家击倒区分，前者不得显示收益；死亡动画不再产生碰撞或奖励。普通靶重生、Boss 击败后补靶、继续存档均保持现有规则。

### V04：反馈与主动技能

已完成。实际实现采用短线、像素碎屑与角标；三技能提示与剩余次数绑定真实状态，同轮同目标浮字合并、跨轮分行。支持“减少特效”，所有瞬时表现设数量上限。结果见 [V04 交接](handoff-v04.md)。

| 事件 | 表现方向 |
| --- | --- |
| 普通命中 | 小范围木屑／碎铁、短受击亮边、简洁伤害数值 |
| 靶心／暴击 | 靶心用准星脉冲，暴击用更明确的金色短闪与数值样式；两者可区分 |
| 贯穿／弹射 | 贯穿用短方向线；弹射沿真实反射方向出现火花 |
| 击倒 | 短破碎动画，经验与金币以有限提示集中显示 |
| 能量达标 | 技能边框一次提示，随后保持稳定就绪状态 |
| 贯日一箭 | 弓口聚光、金色箭头与短尾迹，保持箭体边界可辨 |
| 疾风连弦 | 手臂与弓弦的短残影，用两段状态标记表达剩余次数 |
| 猎手印记 | 目标上方像素符印和细轮廓，避免巨大圆环遮住靶心 |

验收：多箭、分裂和回响密集触发时仍能看到靶心与箭头；同一轮合并重复数值提示，关键暴击/击倒信息保留。表现系统设粒子与浮字上限。沿用屏幕震动开关，并补“减少特效”选项；不使用全屏频闪，不加入改变物理时间的命中停顿。

### V05：主页面与营地

已完成。主页面采用月下游侠与远林，保留左侧操作及右下前三榜；营地用箭架、地图台、装备棚对应入口，集中展示当前冒险、契约与技能锁定。静态场景缓存，披风／飘叶／营火为独立动画层，“减少特效”时静止。结果见 [V05 交接](handoff-v05.md)。

- 主页面采用月下游侠、弓与远林构图；左侧操作区保持明确，插画与文字分层。适度雾层、披风或飘叶让画面有生命感。
- 大厅采用营火、箭架、装备台与地图等场景元素；去射箭、天赋、装扮仍是明确可点击入口。
- 主动技能装备、当前冒险状态、剩余次数在营地中清楚可见。
- 保留排行榜、设置、教程和退出入口；配合已接入的菜单／营地音乐切换。

验收：静态画面即可分辨主页面与大厅；点击区域与视觉入口一致；禁用的继续游戏、当前冒险锁定状态、返回关系不丢失。营地动画不隐式开始战斗或产生收益。

### V07：最终验收

已完成三尺寸页面与八种压力场景检查，修复回响越界和升级返回按钮状态；箭身绘制缓存、碰撞粗筛与已命中普通靶跳过已接入。3182 项自动检查、422 项窗口检查通过。固定重放峰值 387 箭，完整／减少特效的世界快照与 RNG 一致。前后测量及中途波动如实记录于 [V07 交接](handoff-v07.md)；这不是低配实时帧率保证，持续负载和极端浮字拥挤留待 T09-C。

- 对照检查：主页面、营地、默认战斗、Boss 两阶段、三技能、升级、神器三选一／满背包替换、天赋、契约、结算、设置与教程。
- 分辨率：960×540、1280×720、1920×1080。960×540 的世界像素存在非整数缩放，单独检查边缘稳定性；若需要严格像素显示，再加入可选整数缩放与留边，不能把所有尺寸都宣称为像素完美。
- 压力场景：32 支原生箭、每轮最多 64 子箭、弹射与回响联动、多个目标和 Boss 护板同屏。性能采用同机器同场景升级前后比较；具体低配目标待目标硬件确定后记录，不提前承诺帧率。
- 功能：切场景、取消拉弓、极短装填、技能剩余次数、低血量／死亡、暂停、静音与继续读档的表现正确。
- 测试策略：纯资源替换做导入与截图检查；改输入、导航或状态绑定时跑相关测试；最终全量检查一次。视觉随机源与战斗随机源隔离。

## 下一轮的明确范围

当前下一包为 **T09-C2：高密度齐射性能优化**。C1 完成本机普通靶／Boss 各两分钟持续运行、桌面和 WASAPI 状态、独立 Windows release 验证，但普通靶 389 箭场景平均帧间隔仍为 32.74 ms。先定位碰撞与绘制热点，再用相同场景对照优化，不改变战斗规则。低配、跨屏 DPI、长时间听感和小时级运行仍未验收；具体证据见 T09-C1 交接。路线差异仍需真人试玩评价。
