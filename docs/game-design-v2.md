## 1. 页面结构

主页面：开始游戏、继续游戏、设置、教程。

开始或继续后进入游戏大厅，大厅包含：去射箭、天赋、装扮。主页面与大厅是独立页面，背景不运行射箭逻辑。

“去射箭”进入连续靶场。射箭页左上角有“技能”和“背包”（有待选奖励时显示“奇遇”）；HUD 展示剩余拉弓次数、本次箭数、金币、击倒数、得分和等级进度。打开技能面板暂停战斗。

设置包含音量、全屏、屏幕震动和轨迹辅助。教程采用可操作的拉弓、命中、升级引导；教程状态和收益与正式局隔离。

## 2. 永久进度与局内状态

| 状态 | 跨局保留 | 规则 |
| --- | --- | --- |
| 累计经验、等级 | 是 | 击倒靶子得分，得分计入经验 |
| 天赋点、已学天赋 | 是 | 每升一级获得 1 点；后排节点需要更多点 |
| 已解锁和已装备装扮 | 是 | 纯外观，通过等级或累计击倒数解锁 |
| 设置、教程完成情况 | 是 | 与局内进度分开保存 |
| 金币 | 否 | 只供本局购买技能、精通、特性强化与补给；暂停回大厅保留同局钱包，结束/新局清空 |
| 技能、奇遇 | 否 | 每局重新构筑 |
| 本局击倒数、难度 | 否 | 新一局重置 |

“继续游戏”恢复同一冒险及其暂停位置，不重置该局金币、构筑或难度。“新一局”才清空局内状态；不能把返回大厅当成刷初始箭数的入口。

## 3. 弹药、得分与连续靶场

- 箭袋容量代表初始拉弓次数。一次拉弓只消耗 1 次，与这一发射出几支箭无关。
- 所有“恢复箭”“恢复弹药”效果恢复的都是拉弓次数。
- 没有固定关数或过关积分门槛；靶子击倒后短暂延迟补充，持续到本局无法继续射击。
- 剩余次数为 0 时，必须先结算全部在场箭矢、待触发效果和奇遇。如果恢复了次数，就继续战斗。
- 命中本身不提供经验得分；击倒时按该靶子的分值结算一次。靶心和连击主要提高金币。
- 击倒越多，新生成靶子的血量、护甲、分值和金币奖励越高。已有靶子保持生成时的属性快照。
- 新一局重置难度；永久等级和天赋保留。

## 4. 永久天赋：四棵树

| 树根 | 分支一 | 分支二 |
| --- | --- | --- |
| 初始拉弓次数 | 击倒靶子概率恢复次数 | 暴击概率恢复次数，概率较低 |
| 金币获取效率 | 连续命中金币加成 | 靶心额外金币加成 |
| 箭矢基础伤害 | 更高伤害 | 穿甲 |
| 靶子数量与大小 | 超多靶子 | 超大靶子 |

树状界面需要节点连线、前置条件、当前等级、升级效果、点数消耗和锁定原因。

前期基础节点可兼得，同树专精二选一，后续沿对应专精继续进阶。后排节点点数消耗递增，不能简单把整棵树所有节点设为 1 点。每一级经验门槛、每个节点成本、恢复概率均由配置管理。

大厅免费重置天赋，按实际已花费点数返还，不改变玩家等级。

## 5. 局内技能：六个可重复升级方向

| 方向 | 作用 |
| --- | --- |
| 数量 | 增加每发箭数，同时降低单箭伤害 |
| 暴击 | 提高暴击率与暴击伤害 |
| 伤害 | 增加基础伤害 |
| 穿甲 | 提高穿甲值，满足条件后可以贯穿目标 |
| 弹射 | 增加边缘反弹次数 |
| 大小 | 增加箭矢碰撞体积，保持靶心判定公平 |

六类始终可购买，金币不足或达到配置上限时明确提示。技能面板不是随机刷新的商店。

未抵消护甲 = max(靶子护甲 − 箭矢穿甲, 0)。伤害减去未抵消护甲后最低为 1 点。

箭矢穿甲严格大于目标护甲时继续飞行，首版贯穿后不衰减伤害。弹射按命中边界法线反射，默认保持速度大小，奇遇另行修改。

## 6. 奇遇

每累计击倒 10 个靶子触发一次随机三选一；暂停战斗，选择后继续在场箭矢的飞行。一次齐射跨越多个门槛时，各次奖励进入队列，不能丢失或重复领取。

候选生成必须遵守：

1. 每组至少有一个**非特性、无负面代价**的普通选项，例如恢复拉弓次数、提高金币效率。
2. 不能出现三个选项都含 debuff 的情况。
3. 特性类在本局不能重复出现。按当前措辞采用“展示过就移出本局候选池”，包括未选择的特性；跨局重置。
4. 普通增益允许跨次重复；同一次三选一不展示重复卡片。特性池耗尽后由普通增益补足。
5. 暂停、退出和继续游戏不能重抽已经生成的选项。

### 首批奇遇内容

| 类别 | 效果 |
| --- | --- |
| 联动特性 | 贯穿目标后分裂箭矢 |
| 联动特性 | 反弹后速度增加 |
| 联动特性 | 箭矢数量越多，暴击率越高 |
| 转化特性 | 每发箭数归一，按转化前箭数增加伤害与大小 |
| 转化特性 | 暴击率转穿甲：每 2 个百分点暴击率转为 1 穿甲 |
| 转化特性 | 额外暴击伤害转弹射：每 20 个百分点转为 1 次反弹 |
| 普通增益 | 提高金币获取效率 |
| 普通增益 | 增加每发箭数 |
| 普通增益 | 恢复拉弓次数 |

转化是持续规则，后续购买和拾取的属性仍参与计算。暴击倍率 200% 时，只将超出普通伤害的 100% 用于换算，得到 5 次反弹。需保留原始属性与有效属性，不可把原始值永久抹掉后反复转化。

联动与转化的计算顺序必须固定，并在面板显示结果；分裂不能无限递归生成箭矢。

## 7. 待实现时采用的默认规则

以下是为任务可以独立推进而补齐的实现默认值，不冒充额外的用户明确要求。后续可调整，当前无需再次打断确认：

- 天赋在大厅分配；当前局使用开局天赋快照。射箭中升级即获得待分配点，回大厅后分配。
- 返回大厅暂停当前局，不自动结束；重置天赋不改变已开始局的快照。
- 穿甲不足时，即使击倒靶子，箭矢也会停止；击倒本身不提供额外贯穿资格。
- “奇遇”按钮查看已有奇遇和待选奖励；不能自行生成奖励。
- 暴击相关回复按有效暴击命中触发；具体概率与单次触发上限配置化。
- 连击以一次拉弓为单位：至少有效命中一次则延续，整发落空才中断，避免多箭天然破坏连击。
- 普通命中提供手感反馈；金币以击倒奖励为基础，击倒时读取本局连击和最后一击靶心状态，避免反复轻击刷钱。
- 边界碰撞与靶子碰撞分开；同次飞行中对同一个靶子限制重复触发，以防原地刷分。
- “开始游戏”建立或进入永久档案与大厅；大厅中的“去射箭”负责新开一局或恢复当前局。覆盖未结束的一局时明确提示。

具体基础拉弓次数、经验曲线、节点成本、技能价格、成长曲线和奇遇系数属于数值调试，不阻塞架构拆分。

### 新增内容的规则入口

Boss 仍属于同一连续靶场，胜利后继续当前局；金币、技能精通、奇遇强化和补给全部属于局内状态。保留每 10 击倒奇遇、安全普通项保底、特性展示后移出、固定候选继续和现有六特性可兼容的规则。Boss 是否计入普通击倒门槛、阶段间如何补给、成长上限与新特性触发顺序，按 `expansion-plan.md` 的默认规则实施并记录。

用户明确的 Boss 规则：每累计击倒 100 个普通靶子出现一次（100、200、300……）；每一次出现都比上一次更强，新局重置。Boss 入场时剩余普通靶子全部自动碎裂，直到 Boss 被击败才重新生成普通靶；不保留旧靶恢复，也不在 Boss 期间召唤普通靶。自动碎裂默认仅作清场表现，不计真实击倒或发放奖励，入场前真实击倒仍正常结算。

除上述已确认规则外，扩展方案中的数量、阈值、价格和效果强度是开发默认值，不属于用户逐项确认的参数。现有 README 的技能上限和十六种奇遇描述当前可玩版本；完成对应任务包后再改为新的实际行为。

## 10. T11-D已实现：分裂与代价
