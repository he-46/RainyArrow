# V01：战斗场景与 HUD 首次升级

2026-10-17 完成。下一包为 V02 游侠动作与装备。

## 已接入

- 分层夜空、月亮、远山、远林、树冠与枝干、薄雾、边缘树木、地表草石、苔石射箭台及箭架。中央飞行区保持低对比。
- 环境由独立 `ForestBackdrop` 绘制；静态画面使用 CanvasItem 缓存，专属固定种子不接触战斗 RNG。无需外部贴图、动画资源或新插件。
- 顶栏保留等级经验、击倒、剩余拉弓与金币；经验条和 Boss 血条修正最小尺寸，避免挤压文字。
- 主动技能移至下方战斗区域外。贯日、疾风、印记有独立图标；能量每 10 点一格，金线表示技能消耗，可施放时图标变金色；已发动时提示剩余拉弓次数。
- 底栏显示本局得分与连击。完整原有弓箭属性移入 R 面板；F1 展开操作说明。按钮、快捷键与 Esc 关闭均可用。打开时取消正在拖拽的弓，冻结战斗与在途箭，阻止射击及 Q 施放，关闭后继续。
- 第一箭实际射出后淡化操作提示，取消拉弓不触发。教程保留自己的引导，不显示正式局的 R／F1 按钮。

- `scripts/presentation/forest_backdrop.gd`：静态环境。
- `scripts/ui/active_skill_icon.gd`、`energy_ruler.gd`：三技能图案和能量刻线。

- `scripts/gameplay/archery_world.gd`：接入独立背景，保留角色、弓、命中区与原位置。
