## 压力测量方法与限制

- 本机：Intel Core i9-13900HX、NVIDIA RTX 4060 Laptop GPU、驱动日志 581.57；Windows、Godot 4.7.2、Compatibility/OpenGL。
- 960×540 和 1920×1080；普通靶／Boss 二阶段 × 完整／减少特效，共 8 种组合。关闭垂直同步与引擎帧率上限，使用 Dummy 音频后端，保留界面与实际绘制。不是低配测试，也不包含音频设备延迟。
- 每场景固定 120 Hz 重放 720 步，每步渲染一帧；前 120 步预热，后 600 步统计。每 120 步发射 32 箭，共六轮。重放速度取决于机器，**不是实时游戏 FPS**。CPU 步耗时含测试遍历、发射、碰撞和世界更新；渲染帧墙钟耗时另含绘制、调度及帧等待。
- 普通场景 9 面靶，第一面纵向放大以确保 32 母箭真正穿出并触发每轮 64 子箭；目标生命人为设高，仅用于持续压力。Boss 使用实际二阶段与护板。穿甲、反弹、分裂、借壁生风、回声、靶心回响及子箭额外反弹同时开启。人工压力构筑不写入玩家存档，不作为平衡样本。
- 普通靶峰值 **387 箭**，Boss 峰值 **363 箭**；每轮子箭最大 **64**。完整特效峰值 64，减少特效 12，浮字峰值均 24，未突破预算。

以下为 V06 代码基线 → 本轮最终代码 `final2` 的实测，单位 ms：

| 场景／宽度／特效 | CPU 步平均 | CPU 步 P95 | 渲染帧墙钟 P95 |
| --- | ---: | ---: | ---: |
| 普通靶／960／完整 | 7.24 → 5.23 | 9.68 → 7.11 | 31.38 → 15.92 |
| 普通靶／960／减少 | 7.14 → 5.13 | 9.64 → 6.81 | 28.80 → 14.15 |
| Boss／960／完整 | 2.13 → 1.93 | 2.92 → 2.70 | 20.02 → 9.44 |
| Boss／960／减少 | 2.13 → 1.85 | 2.98 → 2.64 | 19.40 → 7.83 |
| 普通靶／1920／完整 | 7.34 → 5.22 | 10.01 → 7.09 | 31.74 → 16.04 |
| 普通靶／1920／减少 | 7.23 → 5.10 | 10.00 → 6.81 | 30.47 → 14.16 |

| Boss／1920／减少 | 2.09 → 1.90 | 2.88 → 2.60 | 18.71 → 7.93 |

不能把这张表推广为稳定帧率保证：中间两轮 `after`／`final` 出现明显波动，普通靶 CPU 平均曾到 13–14 ms、帧墙钟 P95 曾到 35–37 ms；原因未定位，机器功耗、调度与后台负载没有锁定。Boss 代码未新增普通靶跳过逻辑，前后也有耗时波动，因此无法把全部差值归因于单项代码修改。单独交替执行同一组 2 万次碰撞查询，粗筛约 10.6–12.3 ms，精确旧路径约 22.1–23.5 ms，接触计数相同；这只证明局部查询收益。

最后一轮仍出现个别帧尖峰，极端齐射的多个伤害标签仍会拥挤。T09-C 应补长时间真实运行、稳定供电／后台条件、低配、音频声部、跨 DPI 与浮字密度评估。960×540 的世界像素为非整数缩放，不宣称像素完美。
