# T17 交接：自选挑战契约

2026-10-12，用户同意把三档难度改为局外自选契约，现已实装，可用Play.cmd试玩。T01–T08、T10–T17完成，下一包仍是T09-A完整流程/反馈验收。数值曲线提案尚未实装。

## 入口与规则

开始游戏→大厅“自选词条”→按此契约出征。8类各有关闭/I/II，单类互斥、不同类可组合，挑战等级为档位总和0–16。普通/困难/地狱变为可编辑预设，不再叠加旧难度。

| 词条 | I | II | 得分归属 |
| --- | --- | --- | --- |
| 坚固靶材 | 普通靶血量×1.25 | ×1.5 | 普通靶 |
| 铁甲加固 | 普通靶护甲+2 | +4 | 普通靶 |
| 狂暴巨靶 | Boss血量×1.5 | ×2 | Boss |
| 箭袋紧缩 | 初始拉弓−2 | −4 | 全局 |
| 补给短缺 | 每段购买补给上限1 | 禁止购买 | 全局 |
| 物资昂贵 | 技能/精通/神器金币强化×1.25 | ×1.5 | 全局 |
| 轻装出征 | 神器5格 | 4格 | 全局 |
| 狭小靶心 | 普通靶中心高度×.75 | ×.5 | 普通靶 |

预设：普通空；困难health2+boss1（3级）；地狱health2+armor2+boss2+quiver1+supply1+slots1（9级）。新契约统一以普通成长为基线，每击倒+6%基础靶血量；血量契约乘在生成值上。普通靶护甲/靶心限制不影响Boss护甲/弱点。初始次数在天赋基础上扣减，回复量不受影响。禁购补给仍保留Boss胜利回复。价格向上取整，补给原价与Boss免费强化不变。

普通靶类每档+10%普通靶分，Boss类每档+15% Boss分，全局类每档+10%阶段基础分。额外阶段分只在击败Boss时发放，基数为上次Boss结算后普通靶基础分+本次Boss基础分（不含契约倍率）；发放后清零。未击败Boss就结束不发额外阶段分；全部得分同源计经验，金币不变。多箭击倒/重复结算不能重放奖励。

开局后查看页锁定、回大厅/继续保留组合；结果页再来一局沿用该组合。背包按契约显示4/5/6格，原满位替换和丢弃规则保持。排行仍共用本地前三，记录完整组合并支持点击详情，旧模式榜条目保持。

## 实现与兼容

- 新ContractCatalog、ContractsPage；RunModel以challenge返回深拷贝，field_parameters派生血/甲/靶心，skill_price/trait_price统一界面和扣款。
- RunModel contracts=null为兼容旧模式，{}为新零词条；主界面正式开局必传草稿。开始前验证组合，非法参数不会先放弃已有局。
- GameSession按实际defeat_score变化计经验。两个阶段账本存储待结算基础分/累计已发奖励，Boss日志附contract_bonus。结果页和背包历史可查实际阶段分。
- SaveStore封套v22、challenge_schema1；challenge={version,selection,parameters,risk}。规则版本1须保持不可变，后续平衡若改数值要新增规则版本和兼容读取，不能重算旧局。
- JSON整数读成浮点，参数合法性逐项比较并规范化selection，避免字典类型差异误判坏档。
- 旧v21先备份.legacy-v21，保持旧模式全部采样参数、背包/丢弃历史、榜单、世界与在途箭。迁移清理背包仅version<21，清榜仅version<20，不能去掉条件。
- 契约草稿仅本次运行期间保留；已开始的组合随存档永久保存。未加入全组合长局平衡或新曲线。
