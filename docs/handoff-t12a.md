## 交付与默认曲线

六类基础等级/效果保持。基础满级后同一个按钮进入独立精通层；如果下一基础等级已没有任何有效正收益，也提前开放精通，避免花钱买空等级。首次实际精通购买记下本局开放资格，后续奇遇改变来源也不重新锁住。界面显示本阶段等级、价格、有效差异；悬停补充基础/精通等级及精确价格。

精通每方向安全上限100阶。价格ceil(首价×1.18^已购阶数)，最多10亿；收益权重W(n)=Σ(i=0..n−1)1/(1+0.12i)，第1阶权重1，之后每阶渐缓。上限、首价、增长率、衰减和系数都在RunSkillData/data/skills六资源，是开发默认，并未宣称完成长期经济平衡。

| 方向 | 精通来源效果 | 首价 |
| --- | --- | --- |
| 数量 | 前6阶：基础数量减伤因子0.85提高0.02×W(min(n,6))，最多0.98；并有1%×W(min(n,6))伤害加成。6阶后每阶原箭数+1，另加2%×W(n−6)伤害加成 | 150 |
| 暴击 | 暴击率+2个百分点×W(n)，暴击倍率+0.20×W(n)，伤害加成+1%×W(n) | 282 |

| 穿甲 | 穿甲+floor(3×W(n))，伤害加成+1%×W(n) | 889 |
| 弹射 | 反弹+n，穿甲+floor(2×W(n))，初速度+6×W(n) | 177 |
| 大小 | 尺寸+0.15×W(n)，初速度+8×W(n) | 282 |

数量阶段权重在第7阶开始重新从1计，用于后段增伤；第7阶不再追加每箭×0.85惩罚。基础数量等级的指数仍是已购基础等级，精通不修改旧等级。数量原箭数最多参与32来源，归一照旧发射1箭；超过来源上限仍能从增伤获益。暴击100%后仍有暴伤/增伤；转换构筑仍先参与原数量联动及暴击→穿甲/额外暴伤→弹射。弹射/尺寸上限之后分别保留穿甲/初速副收益；整阶没有有效收益时拒购，不为了跨整数阈值收空费用。

精通伤害百分比与箭势渐盛等普通百分比相加。基础、天赋、旧加成、普通奇遇与基础技能加法→精通加法/百分比/数量效率→数量减伤与总伤害百分比→瘦箭/重箭因子→联动/归一/转化→有效上限。整数精通来源按累计权重一次向下取整，加1e-9稳定十进制边界；不会每阶先舍掉小数。伤害100万、箭数32、尺寸6、暴击100%/倍率10、反弹32、速度1000等上限不变。
