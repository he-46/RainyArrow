# V05：主页面与营地

2026-10-18 完成。下一包 V06：构筑界面与图标。

## 已接入

- 主页面使用分层月夜、远山、树林与石台，右上为已装备装扮的像素游侠。左侧保留开始、继续、设置、教程和退出；右下保留可查看条件的本地前三榜。
- 营地用箭架／练习靶、地图台、装备棚／挂衣架建立三个区域，下方对应“去射箭”“天赋”“装扮”按钮。中央增加营火和游侠，木材、羊皮地图、棚布有独立配色。
- 等级、天赋点与当前冒险状态集中在上方。进行中的冒险显示真实剩余拉弓次数、本局金币；契约区域显示锁定状态，主动技能按钮显示本局实际锁定技能，避免与局外后来解锁的装备混淆。
- 保留新冒险确认、取消后继续、排行榜、教程、设置与主页面的返回关系。进入营地不会创建新冒险；只有“去射箭”才建立靶场。
- 展示当前人物、弓、箭的装扮；营地挂衣架和备用弓也沿用装备配色。主页面沿用《月下弓弦》，营地沿用《营火来信》。
- 背景静态绘制后缓存；披风呼吸、四片飘叶、营火与四粒火星放在独立的小动画层，每秒最多刷新约 12 次。开启“减少特效”后回到页面，保留静态构图并停止环境动作。
- 新场景只绘制图形，不创建箭矢、目标、碰撞或游戏随机源。环境层忽略鼠标输入，实际按钮负责操作；战斗在营地保持暂停，等待不回能。
