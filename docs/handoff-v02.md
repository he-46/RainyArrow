# V02：游侠、弓箭与动作

2026-10-17 完成，下一包 V03：普通靶与 Boss 外观。

## 已实现

- 游侠改为有兜帽、短披风、箭袋、肩带、皮革护臂、腰带与靴子的分层像素形象，三套角色、三把弓及三款箭继续独立换装。
- 待机轻微呼吸和披风摆动；拉弓随真实拉力后移手臂；满拉稳定保持；松弦手部后收、弓臂短促回弹；装填从箭袋取箭并回到弦边；成功施放主动技能时抬手。
- 新输入优先于残留的松弦和施法动作，零装填可以立即再拉弓。动画不参与可射击判断，不增加冷却或延迟。
- 弓臂按拉力弯曲。握弓手与弓把保持同一位置，拉弦手与弦中央使用同一计算函数。弓弦回弹不移动发射点。
- 飞行箭使用清楚的菱形箭头、双侧箭羽和分色箭杆；箭头位于实际碰撞圆内。搭箭预览保留固定杆长，大箭表现实际头部半径，多箭最多展示三根搭箭，发射数量仍按真实属性。
- 装扮页使用同一绘制方法，大预览有轻微呼吸，九个小样保持静止。

## 实现与锚点

- `scripts/presentation/archer_pose.gd`：纯表现采样，无随机数、战斗状态写入或输入延迟。
- `scripts/ui/cosmetic_drawing.gd`：角色、独立装备和箭的公共绘制。
- `scripts/ui/cosmetic_preview.gd`：共用姿态与装备锚点。
- `scripts/gameplay/archery_world.gd`：读取拉力、装填、回弹和施法状态。
- 世界原点仍为 `(79, 221)`，脚底本地 `y=60`，落在平台 `y=281`；握弓点本地 `(25, 17)`，对应世界 `BOW=(104,238)`。满拉时搭箭头部中心恰好位于 BOW。原有瞄准范围、拖拽区域、目标和弹射边界均不变。
- 采用代码绘制，未引入位图精灵或外部美术依赖。保存格式不变；读取战斗档后由真实剩余装填时间重建装填姿态，短暂松弦／施法动作不存档、不重复触发技能。
