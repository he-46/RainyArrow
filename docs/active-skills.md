# 主动技能首版

入口：大厅「主动技能」或天赋页「主动技能 →」。首个免费选择并自动装备，其余各 2 天赋点，同时装备一个。正在进行的冒险锁定技能；结束后可自由换装。天赋页的免费重置同时清空技能解锁、返还已付点数，并可重选免费技能；本局技能快照不受影响。

| 技能 | 能量 | 效果 |
| --- | --- | --- |
| 贯日一箭 | 60 | 下一次拉弓的整轮箭伤害 ×2、穿甲 +12 |
| 疾风连弦 | 40 | 立即完成当前装填，随后两次拉弓后的装填为零，正常消耗箭袋 |
| 猎手印记 | 50 | 选择当前瞄准方向 0.38 弧度内最接近的活目标，随后三轮箭对该生命伤害 ×1.6；目标死亡或离场结束 |

按 Q 或点击左下角技能按钮施放。印记灰绿色圈提示候选，金色圈表示已标记；未瞄准有效目标时不扣能量。技能就绪时只能发动一次，已发动的次数不能叠加。额外有 0.25 秒防连按间隔，仅战斗推进时减少。暂停、升级、结算、无剩余拉弓次数与 Boss 待入场时不能施放。

## 能量与箭矢

- 上限 100，新局从 0 开始；实际消耗一次拉弓获得 8 点，取消拉弓没有收益。
- 整轮结算时，至少一次原生箭的有效命中额外 +4，至少一次靶心再 +2。每轮只结算一次，与箭数、命中次数、弹射次数无关。重放结算不能重复回能。
- 分裂子箭、范围回响、护板无伤害命中及主动技能强化伤害不提供额外命中能量。贯日/印记强化的拉弓仍获得基础 8 点，疾风仍是正常原生箭。
- 不通过任何时间计时器恢复能量。暂停、返回大厅、读档保留当前能量。
- 强化按拉弓次数消耗；在途箭记录发射时效果，不受后续购买或洗点影响。分裂继承已快照的强化一次，不重复乘算。
- 印记绑定靶子的生命 ID，普通靶重生后不继承；Boss 护板仍须实际穿甲高于护板护甲才能穿透。印记不增加穿甲。
