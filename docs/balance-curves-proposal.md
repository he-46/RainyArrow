# 数值曲线候选方案：收益、价格与靶场成长联立

日期：2026-10-11。仅为推导和调参候选，未修改游戏运行代码，不替代 T15 已实现规则，也未宣称通过实战平衡验收。

## 1. 先确定数学边界

如果第 n 次升级始终提供至少 g > 0 的相对收益，那么 D(n) ≥ D(0)(1+g)^n，必然至少指数增长。无法同时满足“无限升级、每级固定百分比收益、总数值不指数膨胀”。

推荐让实际等级收益递减，再通过合并购买减少后期无感点击。控制数值时，以累计消费和击倒进度为横轴；合并购买不改变同等花费获得的收益。

本方案保留一个可长期增长的主伤害轴，数量、暴击和增伤乘区有界。神器优先改变触发、覆盖与转换规则。以下参数是计算用默认值，不是用户已逐项确认的配置。

## 2. 主伤害：平移幂函数

D(r) = D0 × (1 + r/K)^p

建议起点：D0 = 24，K = 4，p = 0.65，r 为伤害方向实际等级；基础与精通应组成一条连续曲线，避免切换时跳变。

- D(0) = D0，开局基线不变。
- p ∈ (0,1) 时持续增长、边际绝对收益递减。
- 下一等级相对收益 g(r) = ((K+r+1)/(K+r))^p − 1。
- 当 r 较大，g(r) ≈ p/(K+r)，因此不会维持固定百分比指数上涨。
- 若设计目标为首级提升 g0，可先选 p，再反推 K = 1/((1+g0)^(1/p)−1)。

| 伤害等级 r | 基础伤害 | 下一单级相对提升 |
| --- | ---: | ---: |
| 0 | 24.00 | 15.61% |
| 1 | 27.75 | 12.58% |
| 5 | 40.66 | 7.09% |
| 10 | 54.18 | 4.59% |
| 20 | 76.91 | 2.69% |
| 50 | 130.30 | 1.20% |
| 100 | 199.50 | 0.62% |

天赋的固定伤害应先并入开局 D0，后续伤害等级按一条曲线计算；百分比效果进入增伤池。不能既保留原每级 +8/+12，又叠加完整的新伤害曲线。神器直接提供基础伤害时，也需明确属于基线还是伤害等级来源，不能重复计入。

## 3. 数量：先确定整次齐射收益，再分配单箭权重

N 为归一前的齐射数量，范围 1–32。

Q(N) = N^α，建议 α = 0.35。

每支普通主箭的伤害权重 w(N) = Q(N)/N = N^(α−1)。

α 可以由一箭变两箭的目标收益 g2 反推：α = ln(1+g2)/ln(2)。α = 0.35 对应首次数量收益 +27.46%。

| 箭数 N | 整次齐射倍率 Q | 每支箭权重 w |
| --- | ---: | ---: |
| 1 | 1.0000 | 1.0000 |
| 2 | 1.2746 | 0.6373 |
| 4 | 1.6245 | 0.4061 |
| 8 | 2.0705 | 0.2588 |
| 16 | 2.6390 | 0.1649 |
| 32 | 3.3636 | 0.1051 |

6→7 箭的整次收益为 (7/6)^0.35−1 ≈ 5.54%。这只是同目标、全部命中、未过量伤害时的伤害预算；覆盖不同靶子、暴击分布、护板阻挡与浪费伤害需要实射验证。

数量技能、天赋和神器都先合并为 N，仅计算一次 w，替换当前按数量技能等级累计乘 85% 的规则。额外齐射箭并不额外消耗拉弓次数。

### 必须处理现有固定扣甲

当前是每箭减去 max(护甲−穿甲,0)。如果先缩小单箭伤害再扣甲，整次伤害约为 D×N^α−N×剩余护甲，箭多后仍可能下降。

建议将齐射权重作用在扣甲后的伤害上。设：

- X = 本箭缩放前伤害，已经包含增伤、暴击和命中部位倍率；
- a = max(目标护甲−本箭穿甲,0)；
- d_min = 1，为未分配齐射权重前的最低伤害；
- 本箭实际伤害 = min(剩余生命, w(N) × max(d_min, X−a))。

因此小箭允许造成不足 1 点的浮点伤害。不能给每支小箭再次保底 1 点，否则高箭数又会绕过齐射收益预算。穿甲严格大于护甲才能贯穿的判定仍使用完整穿甲值，不乘 w。

这属于战斗公式语义调整，实施时必须同步处理护板、弱点、真实碰撞、伤害显示、转换与旧局存档；不能只修改数量资源中的一个系数。

归一将 N 支箭合并为一支，单支权重直接为 Q(N)，等价于原每支 w 乘 N；不得再额外乘 Q(N)。分裂继承母箭已采样的权重，不重新按场上箭数归一化。

## 4. 暴击：概率与倍率分别软收敛

u、v 分别为暴击率、暴伤的等效等级来源；技能同时升级时可令 u = v = r_c。天赋/神器来源先折算累加，再统一计算曲线，不能各自套曲线后叠加。

c(u) = 0.10 + 0.90 × u/(10+u)

m(v) = 2.00 + 1.00 × v/(10+v)

这使暴击率趋近 100%，暴击倍率趋近 3 倍。未扣甲暴击期望倍率：E_c = 1 + c(m−1)。

| --- | ---: | ---: | ---: |
| 0 | 10.00% | 2.000 | 1.100 |
| 1 | 18.18% | 2.091 | 1.198 |
| 5 | 40.00% | 2.333 | 1.533 |
| 10 | 55.00% | 2.500 | 1.825 |
| 20 | 70.00% | 2.667 | 2.167 |
| 50 | 85.00% | 2.833 | 2.558 |
| 100 | 91.82% | 2.909 | 2.753 |

概率、暴伤转化使用软收敛后的来源值，再执行清零/回到普通倍率的代价；新数量暴击联动不能插到软上限之后。以上参数与当前 +5%/+0.25 的等级定义不同，实施时需重定神器/天赋等效来源，不可机械沿用旧数值。

## 5. 增伤：统一池与软上限

普通增伤、穿甲转伤害、大小转伤害、反弹后伤害等先产生非负名义增伤，合并为 b：

b = b_普通 + b_天赋 + b_神器 + b_本次命中条件

B(b) = L × b/(L+b)，建议 L = 2.0。

最终增伤乘数为 1+B，而不是将每个来源分别相乘。该曲线在 b 很小时近似 B≈b，后期趋近 +200%，伤害乘数趋近 ×3。

| 名义增伤合计 b | 实际增伤 B | 实际乘数 |
| --- | ---: | ---: |
| +25% | +22.22% | ×1.2222 |
| +50% | +40.00% | ×1.4000 |
| +100% | +66.67% | ×1.6667 |
| +200% | +100.00% | ×2.0000 |
| +400% | +133.33% | ×2.3333 |
| +1000% | +166.67% | ×2.6667 |

穿甲转伤害之类容易随另一属性无限增长的来源，先使用局部软上限。例如穿甲联动：b_穿甲(P) = 0.6×P/(30+P)。10/30/90/270 穿甲分别贡献 15%/30%/45%/54% 的名义增伤，再进入总池 B。这些不是最终独立乘数。

局部上限避免单条联动吃完总池，总池限制多个联动共同膨胀。界面应展示“当前实际伤害→升级后实际伤害”与名义效果，避免名义 +20% 被误解为当前伤害直接 ×1.2。

大小先改变碰撞体积；额外弹射先改变路径；穿甲先影响减甲与贯穿。这些机制收益不直接等价于伤害百分比，联动增伤才进入本节曲线。

## 6. 汇总输出公式与上界

忽略护甲、过量伤害、命中部位和额外命中时：

V ≈ D(r) × N^0.35 × [1+c(u)(m(v)−1)] × [1+B(b)]。

数量≤32、暴击乘区趋近3、增伤乘区趋近3，因此这些乘区合计不超过约 30.27 倍基础伤害。这个上界不包含穿透多个目标、分裂、范围伤害和Boss弱点，不能当成完整实战输出上界。

同一目标、全部主箭命中且没有过量伤害，计护甲后的准确期望为：

V = N^0.35 × {(1−c) max(d_min, F−a) + c max(d_min, mF−a)}

其中 F = D(r)×[1+B(b)]；若普通命中与暴击触发不同条件增伤，必须分别计算各自 F 后加权，不能套用同一个 F。

分裂和范围伤害另设明确预算：例如母箭生成的所有子箭基础权重之和不超过母箭权重的 ρ 倍，再按子箭数分摊；ρ 是神器等级的有界配置。次级范围伤害也需总预算与触发次数限制。额外伤害不能再次生成同类额外伤害。具体预算值要在各神器实射测试后决定。

## 7. 升级价格与累计消费

第 r 级之后再买一级的价格：

C(r) = ceil[C0 × (1+r/S)^q]。

伤害方向建议计算起点：C0=12，S=8，q=1.35。其他方向使用不同 C0，比较收益/金币后调参，不要求同价。

从0级升到r级的实际累计消费 W(r) = Σ(i=0…r−1) C(i)。忽略取整，用积分估计：

W(r) ≈ C0×S/(q+1) × [(1+r/S)^(q+1)−1]。

较大等级时 W∝r^(q+1)，而 D∝r^p，所以：

D∝W^[p/(q+1)] = W^0.2766。

也就是长期累计投入翻倍，主伤害约增加21.13%，不会随累计花费指数膨胀。该推导假设固定比例金币投入此方向，其他购买竞争与补给消耗会影响实际可达等级。

## 8. 后期合并购买：每次操作有感，但不给额外收益

希望一次主伤害购买至少提升 g（例如10%），根据当前等级 r 计算所需等级数：

Δr = max[1, ceil((r+K)×((1+g)^(1/p)−1))]。

合并价格 = Σ(i=r…r+Δr−1) C(i)，不能只收一级价格，也不额外赠送百分比增伤。

| 当前伤害等级 | 合并购买等级数 | 实际伤害提升 | 完整价格 |
| --- | ---: | ---: | ---: |
| 0 | 1 | 15.61% | 12 |
| 10 | 3 | 13.45% | 117 |
| 50 | 9 | 10.54% | 1720 |
| 100 | 17 | 10.34% | 7553 |

表格假设后续等级仍可购买；现有100阶精通上限处必须裁剪或停止，不能越界。若复用当前“基础→精通”两段，需要把两段等级映射到连续曲线后再计算。达到有界属性上限而无法凑足10%时应显示实际收益或停止购买，不承诺虚假的固定提升。

这仍意味着每次完整合并购买后伤害约乘1.1，但每次花费同步增加；它只压缩点击数量，没有改变D对实际等级、金币和击倒进度的曲线。不能将“按点击数看是指数”误称为彻底消除了指数；受控的是单位资源能换到的成长。

## 9. 将靶子成长与经济联立

设 k 为本局普通靶击倒数，单靶基础金币：

G(k) = G0 × (1+k/Kg)^β。

候选 G0=8，Kg=100，β=0.45。实际金币保留小数累积，再乘有界金币效率；不要不断放大金币效率的上限。金币效率、奖励成长不能另加无限指数链。

若金币主要来自普通靶，且投入主伤害的比例大致稳定，累计金币长期约∝k^(β+1)，所以：

主伤害长期约∝k^e，e = p(β+1)/(q+1) ≈ 0.4011。

数量、暴击、增伤封顶后，主伤害成为主要长期成长来源。普通靶生命可用：

H(k) = H0 × M_H × (1+k/Kh)^h。

h≈e 时长期难度趋于稳定；h>e 时逐渐变难；h<e 时逐渐滚雪球。这是选择指数的依据，不能独立随意填写。

候选 H0=48，Kh=25；普通/困难 h=0.45，地狱 h=0.55。M_H 按已确认模式分别1/1.5/1.5。这些参数会大幅低于现有每次击倒+6%基础生命的后期血量，需要与本方案的玩家伤害削减整套测试，不能单独上线。

每100击倒Boss，令b为第几次Boss（从1开始），候选：

HB(b) = 2880 × M_B × [(1+4b)/5]^hB。

普通/困难 hB=0.55，地狱 hB=0.65；M_B=1/2/2。首轮仍2880/5760/5760，后续用幂律增强。固定首轮生命可能与新输出、剩余拉弓次数不匹配，需要实战验收，不是公式自动保证。

护甲也不能继续独立按k线性无限增长、而穿甲却缓慢增长，否则护甲会成为真正决定难度的主轴。建议其成长与预期穿甲等级曲线匹配，以关键Boss的贯穿门槛来校准，保留穿甲严格大于护甲的条件。当前每5击倒+1护甲是否保留，应由穿甲构筑的实射结果决定。

得分/永久经验不参与金币反馈，可独立调整，保留困难×1.5、地狱×2（均以普通为基准）。本方案未指定新得分曲线，避免经济调整同时意外拖慢永久天赋解锁。

此长期推导不包括有限拉弓、回复概率、Boss奖励、神器出现顺序、暴击转穿甲与转换损失；也不能直接推出每局时长。验证必须包含这些条件。

## 10. 实施与验证边界

建议顺序：统一属性来源与增伤池→齐射权重/扣甲顺序→连续伤害和暴击曲线→价格与合并购买→联动/次级伤害预算→靶场/Boss成长→实战调参。

需要覆盖的构筑至少包括单箭重伤、多箭暴击、贯穿分裂、弹射、归一、双暴击转换；分别在低/中/高天赋和三难度测试。记录每次拉弓实际击倒数、Boss消耗次数、下一次有效购买需要的击倒数、剩余拉弓次数和整次结算等待。不能只用未扣甲理论DPS判断平衡。
