## 当前游戏循环

按住弓附近向后拖拽，松开发射。拉得越远，初速度越高；向下拖可抬高弹道。每次拉弓消耗一次机会，多箭齐射也只消耗一次。新契约冒险基础容量为 **16 次**，箭袋续航路线可扩展到 30 次，箭袋紧缩契约再减 2／4 次。已有旧冒险保留原次数，继续游戏不会补发次数；旧固定难度兼容入口仍保留原规则。

命中只扣除靶子血量；**击倒才获得得分、永久经验和本局金币**。每次拉弓的箭矢结束后，按发射顺序结算该次收益和连击。击倒靶子等待至少 1.4 秒且奖励已入账后补充，新靶按已击倒数量提高血量和奖励；在场目标数值不会突然变化。初始木环靶仍为 48 血、40 分、8 金。设本局已击倒 k 个普通靶，新冒险普通靶生命倍率为 **(1 + 0.075k)^0.8**，额外成长护甲为 **floor((k/5)^0.8)**，再应用原有靶型与契约加成；100 击倒时木环靶约 266 血、成长护甲 10。得分／金币仍按基础值 ×(1 + 0.08k) 取整。旧局沿用原先每击倒 +6% 基础血量、每 5 击倒 +1 甲。未被穿甲抵消的护甲直接减伤，最低伤害 1；穿甲严格大于护甲时才能贯穿，击倒本身不赋予贯穿资格。

经验累计到 100、250、450……时升级，每升一级获得一个永久天赋点，支持一次跨多级。大厅天赋页面提供四棵树，每棵9个节点：基础、两条早期分支、两种互斥专精，以及各专精后续的进阶和终极。早期分支可以兼得，同树专精二选一；向下滚动查看后排，点击节点看说明，再点击学习。根节点花费1/2/3点，早期分支2/3点，专精4点，进阶5/7点，终极10点。

每累计击倒 **100 个普通靶子**（100、200、300……），迎来一次「铁弦巨靶」Boss。到门槛后停止补靶，先结清在途箭与本次奇遇，再自动碎裂清除剩余普通靶；清场不提供击倒、金币、经验或回复。Boss 存活期间不生成普通靶。击败后重新生成普通靶，沿用本局难度，继续同一局；齐射超出百次门槛的击倒保留到下一门槛。

Boss 第一阶段静止，金色核心为弱点：伤害 ×1.75 后计算暴击与护甲，弱点护甲比本体低 12。血量降至一半进入第二阶段，本体上下移动，前方护板独立上下移动，形成射击窗口。护板护甲为本体 +8，穿甲严格更高才能穿过；命中护板不扣 Boss 血、不触发暴击或分裂。每支箭对核心和本体共享生命只结算一次，贯穿后分裂与反弹继续使用原规则。

新冒险 Boss 具有**韧甲**：每次拉弓累计扣甲后伤害 D 在最大生命的 20%（T）内正常结算，超过后总承伤为 `T × (1 + ln(D/T))`。主箭、子箭与范围伤害共用同轮额度，弱点、暴击和主动仍能增伤；没有强制锁血。下一次拉弓重新计算，等待和读档不重置。鼠标悬停 Boss 提示可查看当前阈值。旧冒险保留原承伤直到结束。

按用户要求，Boss 血量已整体 ×3：首轮 **2880 血**、20 护甲，第二轮 4608 血，第三轮 6336 血；每轮血量增加首轮的 60%、护甲 +6。首轮基础奖励 1200 得分/经验、240 金币，之后每轮基础奖励增加首轮的 50%，金币仍参与现有收益倍率。Boss 奖励只发一次，不推进普通靶击倒数和十次奇遇门槛；伤害未致死不发奖励。

胜利结清整次箭矢后，额外回复 **3 次拉弓**；每两轮再增加 1 次，最多 6 次，并获得一次 **Boss 战利品选择**。有合格已选特性时提供至多两项免费强化，并保留有收益的安全普通项；没有合格强化时从六种无负面普通增益中抽取至多三项。完全无收益的增益不进入新选项，不占用未展示特性的池。奖励标题显示实际得分、金币和补给；选择后才重新开放普通靶场。最后一箭胜利会先补给并等待选择，退出继续不重抽、不重复补给。已有天赋回复仍独立遵守每次拉弓一次的上限。奇遇记录和结果页展示 Boss 战利品；入场、阶段、护板阻挡/贯穿、弱点命中、胜利使用不同合成音效。免费强化与付费强化共享档位，只消费一次本轮奖励；无任何收益时可保持构筑。

| 万箭归一 | 主箭数量变为 1；按原箭数 N（最多 32）使单箭伤害 ×N、尺寸 ×√N；保留数量技能减伤和分裂 |
| 锋芒换运 | 暴击率变为 0；数量联动后每 2 个百分点暴击率换 1 穿甲，不足不兑换，来源最多 100% |
| 舍锋借势 | 暴击倍率变为 ×1；每 20 个百分点额外暴伤换 1 反弹，200% 倍率的额外 100% 恰为 5 次 |

| 贯穿 / 弹射特性 | 效果（开发默认，可调） |
| --- | --- |
| 越靶越锋 | 穿出受伤靶子后，此箭后续伤害每层 +15%，最多 5 层（+75%）；护板不叠层 |
| 破甲余势 | 穿甲高于本次命中部位护甲的每一点，使本次伤害 +2%，最多 +100%；弱点使用降甲后的数值 |
| 回声重击 | 反弹后的下一次伤害 +50%，命中后消耗；连续反弹只刷新，穿过护板不消耗 |
| 借壁破甲 | 每次真实反弹令此箭穿甲 +3，最多 5 层（+15）；穿甲总值仍限 100 万，不改变角色面板 |

四种新特性与原六种均可组合，无互斥。动态伤害为发射伤害 × 穿靶层数加成 × 已得暴击层数加成 × 本次穿甲余量加成 × 待用回声 × 条件尺寸加成，再按拉力、Boss弱点、暴击及护甲结算；同类层数相加，不同机制相乘。穿出靶子时先加层再分裂，子箭继承已获得层数、此箭穿甲和待用回声，伤害基数仍为母箭一半；未完成的穿靶出口不交给子箭。每次新拉弓从零层开始，旧在途箭不会因新选择变强。强化伤害浮字附带“强化”标记。

| 暴击 / 瞄准特性 | 效果（开发默认，可调） |
| --- | --- |
| 蓄势穿甲 | 本箭额外穿甲为拉力 ×8 向下取整，半拉 +4、满拉 +8；与借壁破甲、破甲余势组合 |
| 靶心回响 | 靶心产生半径 140 的范围伤害，最多 6 个附近靶各受实际主命中伤害的 40%，再减自身护甲 |
| 锋锐回流 | 真正暴击后，本箭后续伤害每层 +12%，最多 5 层（+60%）；当前命中不提前加成 |
| 广锋正中 | 尺寸超出基础 1.0 的每 1.0，提高靶心伤害 15%，连续计算、上限 +75%；Boss 核心适用，判定区不扩大 |

回响不暴击、不连锁、不触发分裂或穿靶/暴击层数；每支箭对每靶最多一次回响，普通靶仍可另受一次实际箭头接触。范围击倒沿同次拉弓结算，击倒才发分数和金币；Boss 本体与核心共享排除，护板不作为范围目标。暴击归零的转化构筑不触发锋锐回流。子箭继承母箭的拉力、已获得暴击层数与范围排除，新选择不改变老箭；回响圈和“回响”浮字显示实际触发，瞬时表现不随读档重播。大小技能预览同时显示靶心增伤。

属性统一按 **原始 → 数量暴击联动 → 归一 → 暴击率转穿甲 → 额外暴伤转反弹 → 有效上限** 计算。转化会持续读取后续技能和普通增益；原始属性不会被抹掉或反复累乘。数量联动读取归一前箭数，子箭不参与。暴伤来源最多额外 900%；有效伤害上限 100 万、尺寸 6、反弹 32。技能按钮显示升级前后实际收益，悬停可看完整计算；奇遇记录也展示所有阶段。归一保留数量技能 85% 的单箭代价，高箭数时伤害收益可能减缓，但尺寸和数量联动继续参与。

| 枝上丰收 | 子箭直击或回响击倒金币+50%，母箭不加；同靶得分/击倒/金币只结算一次，需要已获得一箭生枝 |

十八项特性不新增互斥。子箭两项有分裂前置；两种代价项只在当前实际速度/伤害仍有收益时进入候选，保留安全普通项。因子在原始来源合成后每次只乘一次，再参与原联动/归一/转化和有效上限。新选项不会改变旧在途箭、当前装填或旧母箭随后生成的子箭；子箭金币系数也在发射时冻结，和普通金币倍率相乘，不增加得分。

每组至少一个有实际收益的非特性无负面普通项、同组不重复，不能强迫选择含代价的转化；特性展示后移出本局池，未选择也移出。耗尽池用六种普通项补充，并在所有联动、转化和上限计算后过滤完全无收益的项。合格候选不足三项就显示现有项；没有安全普通收益时提供“保持构筑 · 继续射箭”，不消耗未展示特性，也不重复发放已获得的 Boss 补给。旧存档固定选项不重抽，无收益卡保留并禁用；若旧组的普通项全部无收益，同样可以保持构筑继续。子箭继承母箭的发射属性、剩余反弹、寿命和已命中靶位，但不能再次分裂；同次最多 32 支主箭与 64 支子箭，各有独立命中来源，整次结束后只结算一次。归一限制主箭而保留分裂，子箭继承半伤害的已转化快照；分裂不消耗额外拉弓机会，不增加发射箭数联动。

技能页还可购买**拉弓补给**：每段最多2次，每次+1次拉弓，首价24金，随后按本局累计购买次数×1.6向上取整（24、39、62、99……）。击败Boss恢复下一段额度，价格继续递增；回大厅或读档不刷新。价格、次数和回复量均为可调默认。金币用于基础技能、精通、特性强化和补给，技能页与结果页分别显示累计收入/消费。

拉弓耗尽后先结清所有母子箭、击倒收益、天赋回复和奇遇/Boss奖励；回复可挽救本局。仍为零时，有补给额度且买得起，会出现“购买补给 / 结束本局”。购买继续原靶场，拒绝即结算；缺钱或额度用尽直接结束。结果保留消费、得分和等级/天赋成长，剩余金币清空，结束后不能复活。

- `Esc`：拉弓时取消；其余时候暂停，可返回大厅。
- `F3`：数值与性能面板。
- `M`：静音/恢复。
- 失去焦点会取消拉弓并暂停。

## 页面与继续

主页面包含开始、继续、设置、教程；没有活动局时禁用继续。开始进入大厅；如已有活动局，确认后才放弃本局，永久档案不清空。继续先回大厅，再选择继续射箭。

120 Hz 物理步，圆形箭头沿完整路径扫掠矩形靶子，处理边缘与圆角；箭矢保存发射时属性快照，预览和飞行共用弹道公式。场内碰撞顺序按接触时间处理，反弹后继续本帧剩余运动。当前支持轴对齐靶子；箭矢最多飞行 12 秒，每物理步最多处理 64 次接触，防止极端构筑卡住。表现使用程序绘制像素素材和合成音效，尚无背景音乐和正式美术包。
