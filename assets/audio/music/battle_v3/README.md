# 战斗曲第三轮：《临阵》

根据“旋律太乱，战斗应该认真，听起来像跳舞”的反馈，重写主题与节奏。96 BPM、4/4、32 小节、80 秒，D 小调，以低弦的二分音符脉冲、每两小节变化的长音和声、稀疏圆号与低鼓形成克制的战斗底乐。取消连续跑动旋律、切分伴奏、反拍踩镲和密集鼓花；圆号全曲仅 11 个音，留出长段空白。第 17–24 小节减弱，第 25–32 小节恢复力度。

此版本待用户试听，未接入游戏自动播放。已经认可的 01《月下弓弦》与 03《营火来信》音频和曲谱保持不变。第二轮三版保留作参考，此曲使用新的原创主题。

- 本目录：可循环 OGG、可编辑 MIDI、catalog.json 与音色许可。
- 试听 MP3、WAV 母版和检测记录：`artifacts/bgm/battle_v3/`，属于 Git 忽略产物。
- 复现脚本：`tools/compose_focused_battle.py`，依赖现有 `compose_bgm.py` 与 `compose_battle_variants.py` 的音频辅助函数及工具路径。

以三次连续渲染的中间轮为基础，在起点 45 毫秒混合下一轮真实延续，混响采用环形处理。目标约 −19 LUFS，检查编码后的时长、声道、峰值、循环接缝并验证 Godot 循环导入。MP3 用于试听，游戏循环使用 OGG。技术验证不代表主观听感已经确认。
