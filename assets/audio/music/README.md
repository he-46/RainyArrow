## 文件

- 本目录 `.ogg`：44.1 kHz立体声游戏资源，完整循环；Godot导入设置已打开Loop，起点0，写入速度与拍数。
- 本目录 `.mid`：旋律、和声、低音、鼓的可编辑MIDI。通用MIDI替代音色听起来与成品不同，制作时以OGG/WAV为准。
- `catalog.json`：用途、速度、长度、循环采样边界、音量和技术检测数据。
- `../../../artifacts/bgm/`：MP3试听、16位PCM WAV母版、audition.html试听页及打包文件。此目录被Git忽略，不会随常规源码推送。
- `../../../tools/compose_bgm.py`：本次旋律与合成编曲的可复现源文件，依赖Python、numpy、imageio-ffmpeg。工具可安装到`.tools/music-deps`，不会改系统游戏依赖。

## 使用与验证

OGG首尾直接循环；混响与延迟采用环形尾音，未给循环版加末尾淡出。MP3只用于方便试听，游戏循环优先采用OGG。切换页面或进出Boss时，后续接入宜用约0.6–1.0秒交叉淡化，并将播放器接到已有Music总线，沿用音乐音量设置。

安静曲约−18 LUFS，常规战斗/Boss约−16 LUFS，芯片参考曲约−17 LUFS。全部做了编码后解码、长度、声道、峰值和首尾接缝检查；未削波。技术检测不代替主观试听和与射箭音效的实际混音验收。

复现：安装上述Python依赖后运行 `python tools/compose_bgm.py`，可加 `--track 1` 单独重做一首。主菜单／战斗使用不同主题；统一以拨弦、持续音垫和旋律回复营造像素弓箭氛围。试听确认方向后再做正式配器、长段落和游戏内混音。
